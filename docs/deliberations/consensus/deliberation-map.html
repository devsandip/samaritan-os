What they agreed

Build on Samaritan. Do not adopt OpenClaw or Hermes as the core and do not start over. All three reached this independently in round 1; the rest of the work was detail.

  1. Samaritan is the one place you see tasks and give approvals. One Inbox, one Telegram bot, one audit trail.
  2. Tool-using work runs on the Claude Agent SDK behind a five-method worker interface, so Hermes or OpenClaw can replace it later if a real gap appears.
  3. New views: Now, Activity (every agent run, with a working Stop), Tasks (Cowork-style jobs), per-source notification rules, and an Ask/Delegate bar.
  4. One small MCP server (about eight tools, none that approve) so Claude Code, Claude desktop, Codex and Gemini CLI reach the same memory and inbox.
  5. Thornhill stays the phone controller and drops its own planner and bot. Nutgraf and MailMCP stay as services.
  6. Current Mac first. Phase 0 makes the daemon safe to run unattended; Phase 1 is your meeting workflow.
